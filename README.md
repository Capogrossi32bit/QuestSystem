# Quest System - Practicas Presenciales

## Sistema Blueprint

Para ejecutar las pruebas el jugador debe cargar el mapa L_Quests_Blueprints, iniciar la simulación en interactuar con la caja actor BP_QuestGiver, cada una de las 3 cajas otorga una misión distinta, y pueden acumularse

La interacción en cualquiera de los casos se realiza con la tecla "E", la cual permite recolectar objetos, interactuar, y eliminar enemigos.

## Sistema C++

Para ejecutar las pruebas el jugador debe cargar el mapa L_Quests_PP, iniciar la simulacion en interactuar con la caja actor BP_CPP_QuestGiver, cada una de las 3 cajas otorga una mision distinta, y pueden acumularse

La interacción en cualquiera de los casos se realiza con la tecla "E", la cual permite recolectar objetos, interactuar, y eliminar enemigos.

## Aclaraciones

Por motivos de tiempo, los enemigos son derrotados al interactuar con los mismos, esto puede ser facilmente modificado para que el EventDispatcher sea llamado al derrotar al mismo de manera mas natural.

Por una decisión de diseño, el jugador debe interactuar con el recolectable para recogerlo, de igual manera esto es modificable en caso de que lo requerido sea que el jugador lo recoja simplemente al pasar sobre el mismo.
